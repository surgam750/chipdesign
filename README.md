# chipdesign
本项目面向智能语音设备中的关键词识别任务，基于 E203 处理器平台设计了一款专用硬件加速器，主要用于加快 KWT（Keyword Transformer，关键词识别模型）前馈网络中的线性计算。

关键词识别可以让设备从一段语音中判断是否出现了特定词语，例如设备唤醒词或简单控制指令。这类功能通常需要在资源有限的端侧设备上运行。如果所有计算都交给处理器逐项完成，大量乘法、加法和数据读写会占用较长时间。项目因此设计专门的硬件电路，让多组数据能够并行计算，并尽量减少等待存储器的时间。
系统组成与工作流程
系统由 E203 处理器、前馈线性加速器和共享 SRAM 存储器等部分组成。E203 处理器主要负责配置任务、设置数据地址、启动加速器和接收完成中断；加速器则通过系统总线读取输入数据和模型参数，完成计算后将结果写回共享存储器。

一次标准任务需要将输入矩阵与权重矩阵相乘，并加上偏置，生成完整的输出矩阵。项目设计的计算核心采用双列并行点积结构，能够同时处理两列输出数据；在完成乘加运算后，还会进行舍入和饱和处理，确保结果符合规定的整数数据格式。
主要设计特点
1. 使用量化权重减少数据传输。
项目采用 INT16 输入、INT12 权重和 INT16 输出。可以把量化理解为用更少的二进制位来表示数据：在满足精度要求的前提下，权重所占空间更小，需要从存储器搬运的数据也更少。项目还设计了双列权重连续打包方式，使每项任务的参数数据量相较 INT16 权重参考格式下降约 23.53%。

2. 通过数据复用减少重复读取。
矩阵计算中，同一份输入数据会与多组权重相乘。如果每次计算都重新读取输入，会产生大量重复访存。项目采用输入驻留与列对复用，使已经读取的数据能在片内参与多次计算，降低存储器访问开销。

3. 使用双缓冲协调计算与数据准备。
项目为权重数据设计了双缓冲机制。可以把它理解为准备两个“工作区”：计算单元使用其中一个工作区的数据时，系统可以在另一个工作区准备后续数据，减少计算单元因等待数据而闲置的时间。同时，系统为输出结果预留缓冲空间，保证计算结果能够有序写回。

4. 支持连续任务和参数切换。
不同任务可以使用不同的模型层参数。系统支持在不复位的情况下连续切换参数并执行任务，处理器通过驱动程序提交任务，完成后通过中断获取状态。
验证结果与项目意义
根据项目设计报告，系统进行了组件、计算引擎和 SoC 级别的验证。在 12 项连续任务中，共产生 304128 个整数输出，均与软件参考结果逐位一致。按 150 MHz 工作频率换算，完整任务吞吐量约为 3307.52 项/秒。

数值精度方面，使用 600 个公开样本评估时，12 层参数对应的软件模型最大层归一化均方根误差为 0.033318%。项目还对综合网表进行了逻辑等价检查，报告列出的 79683 个比较点全部匹配；在报告所述约束下，七个工艺角的建立时序检查均满足 150 MHz 目标。

该项目展示了从计算需求分析、数据格式设计、硬件架构设计，到处理器集成、驱动开发和验证分析的一套芯片设计流程。需要注意的是，项目加速的是 KWT 前馈网络的第一线性层；12 项连续任务体现的是不同层参数的切换能力，并不表示完整 KWT 网络已经在硬件上完成级联推理。
